# Humaneframes Landing Page

Premium editorial landing page for Humaneframes, an independent brand and digital studio.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- next/image with local placeholder art slots

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
